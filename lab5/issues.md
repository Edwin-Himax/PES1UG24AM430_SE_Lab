# Lab 5: Identified Static Code Analysis Issues

The following table documents the issues detected across **Bandit**, **Flake8**, and **Pylint** during static analysis of `scholarship_system.py`, prioritized by severity (High and Medium severity issues first).

| Issue | Type | Line(s) | Description | Fix Approach |
| :--- | :--- | :--- | :--- | :--- |
| **Use of Insecure Function (`eval`)** | Security Vulnerability (Medium Severity, CWE-78, Bandit B307 / Pylint W0123) | 12 | Dynamic evaluation of formula string using `eval(MERIT_FORMULA)` allows remote arbitrary code execution (code injection) via untrusted user input. | Replaced `eval()` with a safe Abstract Syntax Tree (`ast`) evaluator (`_safe_eval_formula`) using a strict whitelist of arithmetic operators (`+`, `-`, `*`, `/`) and allowed variable identifiers. |
| **Dangerous Mutable Default Argument** | Bug / Design Flaw (Medium Severity / High Risk, Pylint W0102) | 14 | Parameter `logs=[]` uses a mutable default list shared across all function calls, leading to cross-call state contamination. | Replaced default with `None` (`logs: Optional[List[str]] = None`) and initialized a new list within the function scope when `logs is None`. |
| **Broad Exception Handling (`bare-except` / `try_except_pass`)** | Security / Bug (Low Severity, CWE-703, Bandit B110 / Flake8 E722 / Pylint W0702) | 37–38 | A bare `except:` block with `pass` silently suppresses all exceptions (including `KeyboardInterrupt`, `MemoryError`, `IOError`, and corrupted JSON errors), obscuring runtime failures. | Caught specific expected exceptions `(FileNotFoundError, json.JSONDecodeError, OSError)` and safely initialized fallback behavior. |
| **Resource Management Without Context Manager** | Quality / Resource Leak (Pylint R1732, W1514) | 29, 36 | Files were opened directly using `open()` without a `with` context manager and without specifying character encoding, risking unclosed file descriptors on error and cross-platform encoding errors. | Implemented `with open(filepath, ..., encoding="utf-8") as file_handle:` to guarantee deterministic resource cleanup and consistent UTF-8 encoding. |
| **Shadowing Built-in Identifier** | Code Quality / Namespace Collision (Pylint W0622, W0613) | 11, 16 | The parameter and variable name `credits` shadowed Python's built-in symbol `credits`. Additionally, `gpa` and `credits` triggered unused argument warnings due to implicit `eval` access. | Renamed parameter to `applicant_credits` and variable to `credits_count`, passing them as explicit dictionary context into the evaluator. |
| **Unused Imports (`math`, `sys`)** | Code Smell / Dead Code (Flake8 F401 / Pylint W0611) | 2, 3 | Standard library modules `math` and `sys` were imported but never referenced anywhere in the script, wasting memory and cluttering imports. | Removed unnecessary `import math` and `import sys` statements. |
| **Direct Comparison to Boolean Singleton** | PEP 8 Style Violation (Flake8 E712 / Pylint C0121) | 43 | Condition `if results[r]["eligible"] == True:` performs an explicit equality check against `True` rather than idiomatic Python truthiness testing. | Simplified condition to `if results[r]["eligible"]:`. |
| **Non-conforming Function Name** | Style / Naming Convention (Pylint C0103) | 40 | Function name `printShortlist` used camelCase instead of PEP 8 standard snake_case naming (`lower_case_with_underscores`). | Renamed function to `print_shortlist()`. |
| **Missing Blank Lines & Line Length Violations** | Formatting / PEP 8 Style (Flake8 E302, E305, E501) | 11, 14, 24, 28, 33, 40, 46, 59 | Top-level function definitions had single blank line spacing instead of the mandatory two blank lines, and several lines exceeded 79 characters. | Added standard two blank lines between top-level definitions and wrapped statements to adhere to the PEP 8 79-character limit. |
| **Missing Module & Function Docstrings** | Documentation / Maintainability (Pylint C0114, C0116) | 1, 11, 14, 24, 28, 33, 40, 46 | Neither the module nor its functions contained docstrings explaining their purpose, parameters, return values, or side effects. | Added clear, PEP 257-compliant docstrings to the module and every function. |
